# NanoPHP Starter

Boilerplate inicial para criar aplicações **fullstack** usando [NanoPHP](https://github.com/marinoricardo/nanophp).  
Permite criar APIs REST, Views em PHP e consumir as mesmas APIs no mesmo projeto.

---

## Autor

**Marino Ricardo** – marinoricardo814@gmail.com

---

## Requisitos

- PHP 8.1+
- Composer
- MySQL
- Extensões PHP PDO e mbstring habilitadas

---

## Instalação

Crie um novo projeto:

```bash
composer create-project marinoricardo/nanophp-starter minha-app
cd minha-app
composer install
